Web Designing — Rules & Regulations

RULESET / 01

Round 1 / MCQ Challenge

  • Answer multiple-choice questions related to web technologies.
  • Questions may cover HTML, CSS, JavaScript, web design principles, and responsive design.
  • Complete the round within the allotted time.
  • Top-scoring participants or teams will qualify for Round 2.
RULESET / 02

Round 2 / Replica Design

  • Recreate a website interface using the provided reference design.
  • Match the layout, typography, colours, spacing, and overall visual style as closely as possible.
  • Complete the design within the allotted time.
RULESET / 03

Round 3 / Create Your Own Design

  • Create an original website design based on the given theme or requirements.
  • Creativity, visual appeal, usability, and responsiveness will be evaluated.
  • Complete and submit the design within the allotted time.
RULESET / 04

General Rules

  • Follow the instructions announced by the organizers.
  • External assistance is not allowed unless explicitly permitted.
  • Submit your work before the deadline.
  • The judges’ decision will be final.
